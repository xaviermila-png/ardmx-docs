# Documentació ARDMX

Manual d'usuari i material de vídeo per als dos productes de control DMX
per a pessebres:

- **ARDMX One v2** — ESP32 + MAX485, 4 escenes + 4 transicions per canal.
- **ARDMX EVO** — ESP32 + MAX485 + DFPlayer Mini (àudio complet), mateix
  model d'escenes/transicions que l'One v2.

## Contingut

- [`manual-one-v2.md`](manual-one-v2.md) — manual d'usuari de l'ARDMX One v2.
- [`manual-evo.md`](manual-evo.md) — manual d'usuari de l'ARDMX EVO.
- [`guions-videos.md`](guions-videos.md) — esquelet de guions per als
  vídeos tutorials d'ambdós productes.
- [`imatges/`](imatges/) — captures de pantalla i fotos per als manuals
  i vídeos.
